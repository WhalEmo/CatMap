# 🐾 CatMap

CatMap is a premium, location-based cat media sharing Android application designed with modern development practices. Users can capture photos, tag their location using a custom reactive architecture, and share them within a unified community map.

---

## ✨ Features

- **Premium UI/UX:** Built entirely following Material 3 guidelines, featuring fluid custom animations and reactive, state-driven capsule notifications.
- **Advanced Camera Integration:** Implements **CameraX** for reliable and high-quality image capturing.
- **Custom LocationEngine:** A centralized location system to accurate manage and bind media to geospatial coordinates safely.
- **Firebase Backend:** Utilizes Cloud Storage for reliable image uploading and real-time management.
- **DRY Architecture:** Highly optimized resource management and component reuse to avoid redundancy.

## 🛠️ Tech Stack & Architecture

- **Language:** Kotlin 
- **UI Toolkit:** Jetpack Compose / Material 3
- **Core Components:** CameraX, Firebase Storage, Centralized LocationEngine
- **Architecture:** Clean Architecture with reactive state management
